# M4CR41N
Native Mac Chaos Engine — The ultimate toolkit for Mac-native exploitation, DFU manipulation, and system security research.

## Features
- **Native Implementation:** Built for macOS/Darwin using Navescript.
- **System-Level Control:** Access DFU mode, NVRAM, and kernel-level states.
- **Tool Consolidation:** Centralizes specialized bypass and activation tools.
- **Omega Protocol Integration:** Optimized for Navescript Greek-symbol based scripting.

## Setup
1. Clone this repository.
2. Ensure Navescript runtime is installed.
3. Run tools using `./m4cr41n.nave`.
